## 边界与未闭合事项

- Schema 仍为有界生成器，每个返回候选经过完整根验证。一般字符串否定、复杂引用和交叉约束可能耗尽预算；不能把所有可满足 Schema 都保证求解成功，也不能把预算耗尽说成已证明无解。
- 有限正则支持范围不变，旧 Regex(pattern) 保留最大输出长度预检查；新重载只在有限 AST 内分配长度，稀疏长度仍可能耗尽预算。
- 自动对象支持上述具体类型；无无参构造、其他容器或循环图仍需显式规则/注册。自定义生成器需维护其返回对象自身的不变量及预算契约。
- 核心身份为 domain-v3，内置数据身份为 china-2025-12-31-domain-v3，Schema 搜索身份为 schema-search-v3。旧记录用原实现重放，不会被新规则静默解释。中国区划原始快照没有变化。
- **BLOCKED_EXTERNAL：远程 Windows/Linux CI 未执行。** 已有工作流覆盖两系统，本轮候选仍为未提交的本地改动；不以远程旧提交或重复本地执行冒充同一候选验证。
