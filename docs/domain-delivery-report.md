## 数据完整性和边界

固定版本、原始输入、许可说明、转换规则、源记录数、排除数量与 SHA256 均保留在 manifests 和导入目录中。所有来源本轮已取得并转换，未使用少量硬编码记录替代选定目录。完整范围见 [目录清单](catalog-data-manifest.md)。

- GeoNames 城市取 cities15000 快照（34,180 行），邮编取完整 allCountries 快照（1,826,965 行），不宣称覆盖所有聚落或中国县区邮编映射。
- ROR 完整快照 146,716 个机构、78,918 条机构关系；全部关系目标存在。
- ICD-10-CM FY2027 合并表格层级与完整有序代码，98,403 条；包含第七字符扩展，父级存在且更短，层级无环。
- RxNorm CPC 主文件保留 82,689 个概念代表词与 247,028 个原子词；2,589,722 条来源关系全部保留，按 STYPE 使用 RXAUI 或 RXCUI 校验端点，缺失数为零。
- Crossref 100,000 条图书事实元数据；7 条缺少 DOI/标题及最后原始页 993 条超过上限的记录有明确排除计数，无摘要和全文。
- 车辆模型国家证据、机场代码位置、PCI 厂商设备均来自同一来源关系。生成的 VIN、IMEI、条码等只有约定格式/校验保证，不声明实际分配。

旧内置词库的部分历史来源仍未完整追溯，已在 `data-sources.md` 如实说明；本轮新增来源均有固定输入和通知。公共 API 文档会生成两套 XML，部分新增成员仍有 CS1591 注释完整性警告，功能、测试和包消费门禁不将该警告当作零警告结论。
