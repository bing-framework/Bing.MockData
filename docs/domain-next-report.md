2026-10-25。已先记录 [实施方案](domain-next-plan.md)，完成本轮 N01–N04 的代码、回归、文档和隔离包消费。使用方式见 [功能示例](domain-next-examples.md)。

## 新增能力

1. **Schema 链式依赖**：dependentRequired / dependentSchemas 展开到闭包；新增依赖里的属性、必填项和后续依赖继续参与生成。支持循环依赖的有限闭包。
2. **对象数量规划**：合并 minProperties / maxProperties 后再选择可选字段；补足数量时优先使用已声明属性，支持 additionalProperties=false。空属性名以及 `/`、`~`、`.` 均有回归覆盖。
3. **有限候选交集**：const / enum 按交集选择候选，数学上等价的 JSON 数值和不同键顺序的对象按语义比较。字面量也检查集合、文本、深度和搜索预算。预算内没有找到解仍为 BudgetExhausted，不宣称无解。
4. **可配置航班**：新增 ConfiguredFlight(FlightOptions)，分别配置出发机场、到达机场和航空公司国家，或使用当前目录中的显式记录；配置起飞窗口、时长及 Seats。配置创建时冻结，起降机场必须不同。
5. **独立座位**：Seat(SeatOptions) 支持正整数行号及 A–Z 列范围；遵守文本预算。旧 Flight(string) 保持原有生成规则。

所有 Schema 候选继续通过完整根验证。有限搜索仍不保证任意有解 Schema 均能在指定预算内成功，未扩大这一承诺。新航班仍是模拟路线，座位选项不代表真实飞机布局。
